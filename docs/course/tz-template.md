## 1. Введение

### 1.1. Наименование программы

Planeweave — веб-платформа для совместного планирования задач с графом зависимостей.

### 1.2. Область применения

Кратко: для кого продукт и в какой ситуации используется (1 абзац). Опирайтесь на [`product-brief.md`](product-brief.md).

### 1.3. Актуальность

3–5 пунктов: какую боль решаем, почему списки задач в чатах недостаточны.

### 1.4. Технологические особенности

Краткий список (без деталей реализации):

- клиент-серверная архитектура, доступ через браузер;
- фронтенд: React, TypeScript, ReactFlow;
- бекенд (ментор): Go, Gin, PostgreSQL, JWT, WebSocket;
- синхронизация доски в реальном времени.

## 4. Требования к программному средству

### 4.1. Функциональные требования

#### 4.1.1. Пользовательский интерфейс

**Пользовательские истории** — основной формат требований к UI.

Формат: **Как** [роль], **я хочу** [действие], **чтобы** [результат].

| № | История | Критерии приёмки |
|---|---------|------------------|
| 1 | Как новый пользователь, я хочу зарегистрироваться, чтобы получить доступ к проектам | - [ ] … |
| 2 | … | … |

Минимум **8 историй**. Разделы: авторизация, проекты, доска, зависимости, синхронизация.

#### 4.1.2. Экраны и переходы

| Экран | URL (предложение) | Действия пользователя |
|-------|-------------------|------------------------|
| Вход | `/login` | … |

Схема переходов между экранами (можно ASCII или картинка).

#### 4.1.3. Модель данных

Диаграмма или таблица сущностей: Пользователь, Проект, Задача, Зависимость, Приглашение.

#### 4.1.4. Серверная часть (использование API)

Ссылка на `backend/api/openapi.json` или Swagger UI. Таблица **используемых** конечных точек с назначением.

Практическое руководство: [`backend-dev-guide.md`](backend-dev-guide.md).

#### 4.1.5. Канал синхронизации

Ссылка на `backend/docs/websocket.md`. Таблица событий, которые обрабатывает клиент.

### 4.2. Нефункциональные требования

- Поддержка последних двух версий Chrome и Firefox
- Время отклика интерфейса при локальном API < 200 мс (ориентир)
- Сообщения об ошибках на русском
- Граф зависимостей без циклов (контроль на сервере)

### 4.3. Условия эксплуатации

Кратко: браузер, локальный стенд ментора (`make dev`), без требований к серверному железу.
