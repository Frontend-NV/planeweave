# Planeweave — описание продукта

## Проблема

Команды теряют обзор, когда задачи живут в списках и чатах: не видно, что блокирует релиз, кто за что отвечает, и что можно делать параллельно.

## Решение

Planeweave — общая доска проекта. Задачи — узлы на канвасе, зависимости — стрелки «сначала это, потом то». Несколько человек редактируют одну доску; изменения видны сразу.

## Пользователи

- Участник команды — создаёт задачи, связывает их, меняет статус.
- Владелец проекта — создаёт проект, приглашает людей.

## Основные сценарии

1. Регистрация и вход.
2. Создание проекта и приглашение коллеги по ссылке.
3. Добавление задач на доску, назначение исполнителя, смена статуса (`к выполнению` / `в работе` / `готово`).
4. Связь «задача B ждёт задачу A» — направленная зависимость.
5. Два участника открывают одну доску — правки одного видны другому без перезагрузки страницы.

## Ограничения

- Связи только типа «зависимость» (блокировка), не произвольные заметки.
- Граф зависимостей **без циклов**. Попытка замкнуть цикл отклоняется сервером.
- Задача: название, статус, исполнитель, позиция на доске (x, y).

## Оформление ТЗ (неделя 1)

Шаблон: [`tz-template.md`](tz-template.md). За образец структуры можно смотреть [`docs/examples/ВКР ТЗ.pdf`](../examples/ВКР%20ТЗ.pdf), но для курса достаточно шаблона — полный объём ВКР не требуется.

## Экраны (ориентир для ТЗ и макетов)

1. Вход
2. Регистрация
3. Список проектов
4. Доска проекта (граф + панель задачи)
5. Настройки проекта (участники, приглашение)
6. Принятие приглашения по ссылке

## Вне scope первой версии

- Комментарии к задачам
- Уведомления на email
- История изменений
- Авто-расстановка графа
- Мобильное приложение

## Технические ожидания (для студентов)

- Фронтенд ходит в REST API; документация — Swagger UI (`/swagger/index.html`) и `backend/api/openapi.json`.
- Синхронизация — WebSocket (`backend/docs/websocket.md`).
- Бекенд и стенд предоставляет ментор; студенты реализуют только клиент.
- **Как пользоваться API при разработке:** [`backend-dev-guide.md`](backend-dev-guide.md).
